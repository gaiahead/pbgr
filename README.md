# PBGR — Price to Book Growth Ratio 가치평가 모니터

시장 평가 자본 CAGR 기반 10년 성장 복리 모델로 한국 주요 종목의 **적정 장부가치**를 추정하고,
현재 주가 대비 배수(PBGR)를 시각화합니다.

- **PBGR < 1** → 저평가 (현재가 < 적정가)  
- **PBGR > 1** → 고평가 (현재가 > 적정가)

## 계산 방법

엑셀 모델 기반 Python·JavaScript 구현:
- **PBGR·적정가·괴리율**: 최신 실제 지배주주 자본총계를 기준 월말부터 현재까지 시장 평가 자본 CAGR으로 성장시켜 현재 자본을 구하고, 그 현재 자본을 다시 정확히 10년 성장시킨 뒤 요구수익률로 10년 할인
- **시장 평가**: 현재 종가와 적정가가 같아지는 자본 CAGR을 `최근 → 현재 → 현재+10년`의 동일한 시간축으로 역산하며, 종목별로 수정·저장·초기화 가능
- **실적·컨센서스 자본 CAGR**: JSON 감사자료로만 유지하며 현재 화면 가치평가에는 사용하지 않음
